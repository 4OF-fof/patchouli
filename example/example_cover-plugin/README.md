# example_cover

タグとプロジェクトの概要にカードを足す例です。「概要を編集」の「セクションを追加」から 2 枚のカードを置けます。

- 「目標」は件数の目標と進み具合を出します。目標は編集中に入れ、カードごとに残ります。タグではサブタグで絞り込んでいればそのあとの件数を数えます。
- 「月ごとの件数」は項目を更新した月ごとに数え、直近 6 か月の棒にします。

## 作り

| ファイル      | 中身                                                                                                        |
| ------------- | ----------------------------------------------------------------------------------------------------------- |
| `plugin.json` | `covers` にカード `goal`・`months` を書く。`goal` は `on` で置ける画面を書き、`months` は書かずに両方に置く |
| `ui.ts`       | `covers` の `mount` で描く。`goal` は `api.value`・`api.setValue` で目標を残し、`api.onEditing` で入力欄を出し入れする |

`node scripts/dev-library.ts` が SDK の CLI でビルドし、開発中のアプリに入れます。確認用のライブラリではタグ「写真」とプロジェクト「秋の企画」の概要に、このカードが入っています。
