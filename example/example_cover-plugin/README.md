# example_cover

タグとプロジェクトの概要欄にカードを追加する実装例です。「概要を編集」の「セクションを追加」から 2 種類のカードを配置できます。

- 「目標」は目標件数と現在の達成状況を表示します。目標件数は編集モード中に入力でき、カードごとに保存されます。タグ画面でサブタグによる絞り込みを行っている場合は絞り込み後の件数を集計します。
- 「月ごとの件数」は項目を更新月ごとに集計し、直近 6 か月分の棒グラフを表示します。

## 構成

| ファイル      | 内容                                                                                                                 |
| ------------- | -------------------------------------------------------------------------------------------------------------------- |
| `plugin.json` | `covers` に `goal`・`months` を定義。`goal` は `on` で対象画面を指定し、`months` は省略して両方の画面に対応           |
| `ui.ts`       | `covers` の `mount` で描画。`goal` は `api.value`・`api.setValue` で目標件数を保存し、`api.onEditing` で入力欄を切り替え |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。動作確認用ライブラリではタグ「写真」とプロジェクト「秋の企画」の概要にこれらのカードが配置されています。
