# example_chart

ノートのコードブロックの例です。中身は 1 行に 1 つの「名前: 数」です。

- `bars` は WASM が棒グラフの SVG にします。
- `tally` はスクリプトが描きます。行ごとの − と + で数を書き換え、下に WASM の棒グラフを出します。
- ノートの `/` のメニューに「棒グラフ」と「数える表」を足します。

## 作り

| ファイル      | 中身                                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------------- |
| `plugin.json` | `notes` の `code` に `bars`・`tally` を書き、`script` に `tally` を書く。`slash` で `/` のメニューに 2 つ足す |
| `src/lib.rs`  | `code-role` を export し、`render` で棒グラフの SVG を返す                                              |
| `ui.ts`       | `code` の `tally` の `render`・`update` で表を描き、`api.setSource` で数を書き換え、`api.wasm()` で棒グラフを出す |

`node scripts/dev-library.ts` が SDK の CLI でビルドし、開発中のアプリに入れます。確認用のライブラリの「記法の見本」に、この 2 つのコードブロックが入っています。
