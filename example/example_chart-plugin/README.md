# example_chart

ノートのコードブロックの実装例です。各行に `名前: 数値` の形式でデータを記述します。

- `bars` は WASM で棒グラフの SVG を生成します。
- `tally` はスクリプトで描画します。行ごとの `−` / `+` ボタンで数値を増減でき、下部に WASM が生成した棒グラフを表示します。
- ノートの `/` メニューに「棒グラフ」と「数える表」を追加します。

## 構成

| ファイル      | 内容                                                                                                      |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| `plugin.json` | `notes` の `code` に `bars`・`tally`、`script` に `tally` を指定し、`slash` で `/` メニューに 2 項目を追加 |
| `src/lib.rs`  | `code-role` を export し、`render` で棒グラフの SVG を返す                                                |
| `ui.ts`       | `code.tally` の `render`・`update` でカウンター表を描画し、`api.setSource` で更新、`api.wasm()` で棒グラフを表示 |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。動作確認用ライブラリのノート「記法の見本」にこの 2 つのコードブロックが含まれています。
