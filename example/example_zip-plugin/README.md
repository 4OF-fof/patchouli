# example_zip

WASM とスクリプトを組み合わせてファイル形式に対応するプラグインの実装例です。ZIP ファイルのサムネイルにアイコンを生成し、詳細画面ではアーカイブ内の構造をフォルダツリーで表示します。

- サムネイルは WASM が描画したアイコンの PNG です。
- ファイル一覧は WASM が ZIP の中央ディレクトリのみを読み取って取得します（ZIP64 にも対応）。
- 詳細表示はスクリプトが描画します。各フォルダにはファイル数と合計サイズを表示し、展開時に子要素を描画します。

## 構成

| ファイル      | 内容                                                                                      |
| ------------- | ----------------------------------------------------------------------------------------- |
| `plugin.json` | `formats` の `zip` の `parts` に `thumbnail`・`view` を指定し、`script` に `view` を指定  |
| `src/lib.rs`  | `thumbnail-role` と `call-role` を export し、`call` の `entries` でファイル一覧を JSON で返す |
| `src/icon.rs` | `tiny-skia` でアイコンを描画して PNG にエンコード                                         |
| `ui.ts`       | `mount` で `api.call('entries')` を呼び出し、フォルダツリーを描画                         |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。動作確認用ライブラリにはサンプルの ZIP ファイルが含まれています。
