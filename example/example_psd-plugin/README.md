# example_psd

WASM のみでファイル形式に対応するプラグインの実装例です。PSD ファイルの合成画像をサムネイルと詳細画面に表示し、解像度・カラーモード・ビット深度・レイヤー数をファイルの詳細欄に追加します。

- 保存時に埋め込まれた合成画像のみを読み取り、レイヤーごとの合成は行いません。
- 非圧縮および PackBits 圧縮に対応し、PSB（大型ドキュメント形式）も読み取れます。
- カラーモードは RGB・グレースケール・CMYK・インデックスカラー・白黒 2 値に対応し、その他のモードは輝度チャンネルからグレースケールとして表示します。
- ビット深度は 1・8・16・32 ビットに対応します（32 ビットはガンマ補正して 8 ビットに変換）。
- WebView 標準では PSD を表示できないため、詳細表示では `decode` が元サイズの PNG を生成して返し、アプリ本体がその PNG をキャッシュします。

## 構成

| ファイル      | 内容                                                                                 |
| ------------- | ------------------------------------------------------------------------------------ |
| `plugin.json` | `formats` の `psd` の `parts` に `thumbnail`・`view`・`details` を指定               |
| `src/lib.rs`  | `thumbnail-role`・`view-role`・`details-role` を export し、合成画像を PNG に変換    |
| `src/psd.rs`  | PSD ヘッダーとレイヤー数を解析し、合成画像を縮小しながら RGB / RGBA ピクセルに変換   |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。動作確認用ライブラリにはサンプルの PSD ファイルが含まれています。
