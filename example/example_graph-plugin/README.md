# example_graph

右クリックメニューから別のウィンドウを開く例です。選んだノートを真ん中に置き、リンクでつながるページを円の上に並べた「ページの関係図」を開きます。

- リンクは書いた側と書かれた側のどちらからもたどります。たどる段の数は 1 か 2 を選べ、ライブラリごとに残ります。
- ページを押すと本体のウィンドウで開きます。中クリックか Ctrl を押しながらのクリックでは、新しいタブで開きます。
- ライブラリが変わると描き直します。

## 作り

| ファイル      | 中身                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| `plugin.json` | `menu` を `md`・`elevated` にし、`screens` に `place: false` とウィンドウの大きさを書いた画面 `graph` を書く |
| `ui.ts`       | `runMenu` で `{ screen: { id: 'graph', window: true } }` を返し、`screens.graph.mount` で図を描く            |

`node scripts/dev-library.ts` が SDK の CLI でビルドし、開発中のアプリに入れます。
