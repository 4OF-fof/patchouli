# example_graph

右クリックメニューからカスタム画面を開く実装例です。選択したノートを中心に、リンクでつながるノートを同心円状に配置した「ページの関係図」を表示します。

- リンク元・リンク先の双方向をたどります。たどる深さは 1 段または 2 段から選択でき、設定はライブラリごとに保存されます。
- ノードをクリックすると該当ノートを開きます。中クリックまたは Ctrl+クリックでは新しいタブで開きます。
- ライブラリの内容が変更されると自動で再描画されます。

## 構成

| ファイル      | 内容                                                                                 |
| ------------- | ------------------------------------------------------------------------------------ |
| `plugin.json` | `menu` に `md` を指定し、`screens` に `place: false` の画面 `graph` を定義           |
| `src/lib.rs`  | `menu-role` を export し、`run_menu` で `MenuOutput::Screen("graph")` を返す         |
| `ui.ts`       | `screens.graph.mount` で SVG による関係図を描画                                      |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。
