# example_autolink

取り込みのフックの例です。md を取り込んだとき、本文に出てくるノートの名前のうち、内容の近いものをそのノートへのリンクにします。

- 近いノートは、EmbeddingGemma で本文と比べて探します。AI 機能を有効にし、モデルを入れたときだけ動きます。
- それぞれのノートは、本文で最初に出てくるところだけをリンクにします。
- コードブロック・インラインのコード・見出し・すでにあるリンクの中は書き換えません。
- 取り込んだあと裏で動き、動いているあいだは作業の表示に出ます。

`取り込む見本.md` を開発中のアプリに取り込むと、確認用のライブラリのノート（配色ガイド・ポスター構成など）へのリンクが付きます。

## 作り

| ファイル      | 中身                                                                                                 |
| ------------- | ---------------------------------------------------------------------------------------------------- |
| `plugin.json` | `hooks` の `added` に `md` を書き、`permissions` に `library`・`notes`・`embed` を書く               |
| `src/lib.rs`  | `hook-role` を export し、`added` で `embed::similar` を呼んで、`notes::set_body` で本文を書き換える |

`node scripts/dev-library.ts` が SDK の CLI でビルドし、開発中のアプリに入れます。
