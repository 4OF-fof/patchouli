# example_autolink

フックの実装例です。`.md` ファイルを取り込んだときと編集後に画面を離れたとき、本文内に出現するノート名のうち内容の近いノートへのリンクを自動で付与します。

- 内容の近いノートは EmbeddingGemma によるベクトル類似度で検索します。AI 機能が有効かつモデルがインストールされている場合のみ動作します。
- 各ノート名につき本文内で最初に出現する箇所のみをリンク化し、すでにリンクが存在するノートはスキップします。
- コードブロック・インラインコード・見出し・既存のリンク内は書き換えません。
- バックグラウンドで実行され、実行中はタイトルバーの「処理中」に表示されます。AI 機能が無効な場合は、取り込み時のみエラー通知を表示します。

`取り込む見本.md` を開発中のアプリに取り込むと、動作確認用ライブラリ内のノート（「配色ガイド」「ポスター構成」など）へのリンクが自動で付与されます。

## 構成

| ファイル      | 内容                                                                                                  |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| `plugin.json` | `hooks` の `added` と `changed` に `md` を指定し、`permissions` に `library`・`notes`・`embed` を指定 |
| `src/lib.rs`  | `hook-role` を export し、`hook` 内で `embed::similar` と `notes::set_body` を呼び出す                |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。
