# example_collect

WASM で右クリックメニューに項目を追加し、選択した項目からノートを作成する実装例です。

- 素材は本文に埋め込み、ノートは「ページ」見出しの下にリンク一覧として並べます。
- 新しいノートは選択した先頭項目と同じ所属（プロジェクト・グループ）に作成され、完了時にトースト通知を表示します。

## 構成

| ファイル      | 内容                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------- |
| `plugin.json` | `menu` に `"all"` を指定し、`permissions` に `library` と `notes` を指定                  |
| `src/lib.rs`  | `menu-role` を export し、`run_menu` で `library::item` の読み取りと `notes::create` を実行 |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。
