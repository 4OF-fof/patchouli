# example_page

プラグインでカスタム画面を追加する実装例です。すべてのノートをカード形式で一覧表示する画面「ノートのカード」を追加します。

- ナビゲーションメニュー・コマンド・起動時に開く画面から開けます。
- ピン留めされたノートを先頭に表示し、残りを更新順または名前順で並べます。並び順はライブラリごとに保存されます。
- 各カードには本文内で最初に埋め込まれた素材のサムネイルを表示し、埋め込みがない場合は本文の冒頭数行を表示します。
- カードをクリックするとノートを開きます。中クリックまたは Ctrl+クリックでは新しいタブで開きます。
- 「新しいノートを作成」ボタンで新規ノートを作成して開きます。

## 構成

| ファイル      | 内容                                                                   |
| ------------- | ---------------------------------------------------------------------- |
| `plugin.json` | `screens` に画面 `cards` を定義し、`script` に `ui.js` を指定          |
| `ui.ts`       | `screens.cards.mount` でカード一覧画面を描画                           |

`node scripts/dev-library.ts` を実行すると SDK の CLI でビルドされ、開発用ライブラリに導入されます。
