# example_page

プラグインで画面を足す例です。すべてのノートをカードにして並べる画面「ノートのカード」を足します。

- 場所のメニュー・コマンド・起動時に開く画面から開けます。
- ピン留めしたノートを先に並べ、残りは更新した順か名前の順に並べます。並べ方はライブラリごとに残ります。
- カードには、本文で最初に埋め込んだ素材のサムネイルを出します。埋め込みがなければ本文の頭の数行を出します。
- カードを押すとノートを開きます。中クリックか Ctrl を押しながらのクリックでは、新しいタブで開きます。
- 「新しいノート」でノートを作って開きます。

## 作り

| ファイル     | 中身                                                     |
| ------------ | -------------------------------------------------------- |
| `plugin.json` | `screens` に画面 `cards` を書き、描くのは `script` の `ui.js` |
| `ui.ts`      | `screens.cards.mount` で、渡された要素の中に描く             |

`node scripts/dev-library.ts` が SDK の CLI でビルドし、開発中のアプリに入れます。
