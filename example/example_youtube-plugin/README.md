# example_youtube

URL のプラグインの例です。組み込みの YouTube のプラグイン（`app/plugins/youtube/`）を写したもので、`id` と `name` だけを変えてあります。

- サムネイルは動画の ID から決まる画像を取ってきます。
- 詳細の表示とノートへの埋め込みには、埋め込みのプレーヤーを使います。
- ファイルの詳細には oEmbed で取ったタイトルを足します。

組み込みのものと同じホスト名を受け持つので、両方を入れるとどちらも使われなくなります。確認用のライブラリには入れません。

## 作り

| ファイル         | 中身                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------- |
| `plugin.json`    | `links` に `youtube.com` と `youtu.be` を書き、`fetch` に取りに行くホスト名を書く                     |
| `ui/youtube.ts`  | `links` の `thumbnail`・`mount`・`embed`・`details` を書く                                            |

SDK の CLI でビルドすると、アプリの「インストール」で選べる zip になります。
