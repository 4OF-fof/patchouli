# example_youtube

URL に対応するプラグインの実装例です。コア機能の YouTube プラグイン（`app/plugins/youtube/`）と同じ実装で、`id` と `name` のみ変更しています。

- サムネイルは動画 ID からサムネイル画像を取得して生成します。
- 詳細表示とノートへの埋め込みには YouTube の埋め込みプレーヤーを使用します。
- ファイルの詳細欄には oEmbed で取得した動画タイトルを追加します。

コア機能と同じホスト名を対象とするため、両方を有効にすると競合となりどちらも使用されなくなります。そのため動作確認用ライブラリには既定では導入されません。

## 構成

| ファイル        | 内容                                                                     |
| --------------- | ------------------------------------------------------------------------ |
| `plugin.json`   | `links` に `youtube.com` と `youtu.be`、`fetch` に接続先ホスト名を指定   |
| `ui/youtube.ts` | `links` の `thumbnail`・`mount`・`embed`・`details` を実装               |

SDK の CLI で `zip` サブコマンドを実行すると、アプリの「プラグインを追加」からインストールできる ZIP ファイルが生成されます。
