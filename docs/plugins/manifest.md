# plugin.json

型は SDK の `manifest.ts`（`Manifest`）。アプリは読み込むときに中身を確かめ、合わないところをプラグインの一覧の「問題」に出す。

```json
{
  "id": "example_zip",
  "name": "example_zip",
  "version": "0.1.0",
  "description": "zip のサムネイルにアイコンを描き、詳細では中身をフォルダの木で見せる",
  "elevated": "ui.js",
  "formats": {
    "zip": { "label": "zip", "ratio": 1, "fit": "contain", "sandbox": true, "elevated": ["view"] }
  }
}
```

## 上の階層

`formats`・`links`・`screens`・`menu`・`hooks` のどれか 1 つは書く。

| キー          | 中身                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| `id`          | プラグインの ID。組み込みのプラグインと同じものは使えない                                                    |
| `name`        | 一覧に出す名前                                                                                               |
| `version`     | 版（semver）。ライブラリに記録した版と違うと、一覧に更新のボタンが出る                                       |
| `description` | 一覧に出す説明                                                                                               |
| `elevated`    | elevated のビルド後の `.js` のパス（plugin.json からの相対）。元は拡張子を `.ts` にしたもの                  |
| `formats`     | 拡張子（小文字・`.` なし）→ その形式で受け持つもの                                                           |
| `links`       | URL のホスト名 → その URL で受け持つもの                                                                     |
| `screens`     | 画面の ID → 足す画面                                                                                         |
| `menu`        | 右クリックメニューに項目を足す対象                                                                           |
| `hooks`       | 取り込んだときに呼ぶ対象                                                                                     |
| `permissions` | WASM に渡すホストの関数（下の表）                                                                            |
| `required`    | ないと動かないコマンドとプラグイン                                                                           |
| `optional`    | あれば使うコマンドとプラグイン                                                                               |
| `fetch`       | elevated の `api.fetch` で取りに行けるホスト名。サブドメインも含む                                           |

## formats

| キー          | 中身                                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `extends`     | 引き継ぐ形式。自分で受け持たないものと、書いていないキーはそちらのものを使う。循環すると問題になる                      |
| `label`       | 形式の呼び名                                                                                                            |
| `ratio`       | サムネイルができるまで使う縦横比（幅 / 高さ）                                                                           |
| `fit`         | サムネイルの枠への収め方。`center`（既定）・`top`（上の端を残して切り抜く）・`contain`（切り抜かずに収める）            |
| `hover`       | カーソルを合わせたときに本体が見せるもの。`video` は元のファイルを音を消して再生し、`audio` は音を再生する              |
| `embed`       | ノートに埋め込んだときに本体が見せるもの。`view`（既定・詳細と同じ表示）か `card`（サムネイルと名前）                   |
| `sandbox`     | `true` にすると、WASM が export する役割を受け持つ                                                                      |
| `elevated`    | elevated が受け持つものの並び（下の表）                                                                                 |
| `keepDecoded` | `view` の `decoded` で作った PNG を取っておけるようにする。取っておくかは、本体が足す設定の項目で選ぶ                   |

受け持てるものは次のとおり。`sandbox` と `elevated` の両方に書いたものは elevated を使う。

| もの        | 中身                                                     | sandbox | elevated |
| ----------- | -------------------------------------------------------- | ------- | -------- |
| `thumbnail` | サムネイル                                               | ○       | ○        |
| `view`      | 詳細の表示                                               | ○       | ○        |
| `details`   | ファイルの詳細に足す行                                   | ○       | ○        |
| `content`   | 内容で探したり分けたりするときに読む区間                 | ○       | ○        |
| `waveform`  | 音の波形                                                 |         | ○        |
| `hover`     | カーソルを合わせたときにサムネイルの上に重ねる表示       |         | ○        |
| `embed`     | ノートに埋め込んだときの表示                             |         | ○        |
| `link`      | ファイルが指す URL（ショートカットなど）                 |         | ○        |

- 同じ拡張子を複数のプラグインが書くと、どれも使わない
- `link` を受け持つ形式のサムネイル・詳細の表示・埋め込み・ファイルの詳細は、ほかに受け持つものがなければ、URL に当てはまる `links` のプラグインか本体が受け持つ

## links

```json
"links": {
  "youtube.com": { "elevated": ["thumbnail", "view", "embed", "details"] }
}
```

- ホスト名はサブドメインも含む。当てはまるものが複数あれば、いちばん長いホスト名のものを使う
- 受け持てるのは `thumbnail`・`view`・`embed`・`details` で、elevated だけが受け持つ
- 同じホスト名を複数のプラグインが書くと、どれも使わない

## screens

```json
"screens": {
  "graph": { "label": "ページの関係図", "icon": "diagram", "place": false, "window": { "width": 720, "height": 560 } }
}
```

| キー     | 中身                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| `label`  | 場所のメニューやタブに出す名前                                                       |
| `icon`   | 本体のアイコンの名前（`home`・`grid`・`note` など）。書かないときはプラグインのアイコン |
| `place`  | 場所のメニュー・コマンド・起動時に開く画面に並べるか。既定は `true`                  |
| `window` | 別のウィンドウで開いたときの大きさ（px）。既定は 480 × 640                           |

- 画面の ID には英数字・ハイフン・下線を使う
- `place` が `false` の画面は、右クリックメニューの結果の `screen` で開く

## menu と hooks

```json
"menu": { "formats": ["csv", "tsv"], "by": "sandbox" },
"hooks": { "added": { "formats": ["md"], "by": "sandbox" } }
```

| キー      | 中身                                                                                         |
| --------- | -------------------------------------------------------------------------------------------- |
| `formats` | 拡張子の並び、`all`（ノートも含めたすべて）、`files`（ノートを除いたすべて）のどれか。ノートは `md` |
| `by`      | `sandbox` は WASM、`elevated` は elevated が受け持つ。`hooks` は `sandbox` だけ               |

- `menu` は、選んだものがすべて `formats` に入るときだけ項目を足す。対象が重なるプラグインの項目は、プラグインごとに区切って並ぶ
- `hooks` の `added` は、アプリで取り込んだもの 1 つごとに裏で呼ぶ。同じ形式のフックはプラグインの一覧の順に呼ぶ

## permissions

WASM で使う関数のまとまりを書く。書いていないものを import する WASM は読み込まない。関数は [wasm.md](wasm.md#ホストの関数) に書いてある。

| 値          | できること                                   |
| ----------- | -------------------------------------------- |
| `library`   | 素材やノートの名前・タグ・プロジェクトを読む |
| `embed`     | 文章をベクトルにし、近い素材とノートを探す   |
| `clipboard` | クリップボードに写す                         |
| `notes`     | ノートを作り、本文を書き換える               |
| `edit`      | 名前とタグを変える                           |
| `assets`    | 素材を登録し、中身を置き換える               |
| `export`    | ライブラリの外へ書き出す                     |

## required と optional

```json
"optional": {
  "commands": {
    "ffmpeg": {
      "version": { "args": ["-version"], "pattern": "ffmpeg version n?([0-9][^ ]*)" },
      "min": "6.0",
      "description": "AVIF のサムネイルを作れます"
    }
  },
  "plugins": { "patchouli.image": { "min": "0.4.0" } }
}
```

| キー                   | 中身                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------- |
| `commands.<名前>`      | 手元のコマンド。PATH から探す。WASM の `commands` で動かせるのは、ここに書いたものだけ |
| `commands.<名前>.min`  | 版の下限。書くときは `version` も書く                                                  |
| `commands.<名前>.version` | 版の取り方。`args` で動かし、出力から `pattern` で拾う（グループがあれば最初のグループ） |
| `commands.<名前>.description` | 何に使うか。一覧に出す                                                          |
| `plugins.<id>.min`     | ほかのプラグインの版の下限。elevated の `api.plugin(id)` で、その WASM を呼べる        |

`required` を満たさないプラグインは使えない。`optional` を満たさないときは、一部の機能を使えないと一覧に出す。
