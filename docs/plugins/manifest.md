# plugin.json

型定義は SDK の `manifest.ts`（`Manifest`）にある。アプリは読み込み時に内容を検証し、不備があればプラグイン一覧のエラー・警告として表示する。

```json
{
  "id": "example_zip",
  "name": "example_zip",
  "version": "0.1.0",
  "description": "ZIP のサムネイルにアイコンを描画し、詳細画面では中身をフォルダツリーで表示",
  "script": "ui.js",
  "formats": [
    { "ext": ["zip"], "label": "ZIP", "ratio": 1, "fit": "contain", "parts": ["thumbnail", "view"], "script": ["view"] }
  ]
}
```

## トップレベル

| キー          | 内容                                                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`          | プラグインの ID。コア機能と同じ ID は使用できない                                                                                                |
| `name`        | プラグイン一覧に表示する名前                                                                                                                     |
| `version`     | バージョン（semver）。ライブラリに記録されたバージョンと異なる場合は更新ボタンが表示される                                                       |
| `description` | プラグイン一覧に表示する説明                                                                                                                     |
| `script`      | ビルド後のスクリプト（`.js`）の `plugin.json` からの相対パス。ソースファイルは拡張子を `.ts` にしたもの                                          |
| `formats`     | 対応する拡張子設定の配列                                                                                                                         |
| `links`       | 対応する URL 設定の配列                                                                                                                          |
| `screens`     | 画面 ID → 追加する画面の設定                                                                                                                     |
| `notes`       | ノートに追加するコードブロックと言語・`/` メニュー項目の設定                                                                                     |
| `covers`      | カード ID → タグやプロジェクトの概要に追加するカードの設定                                                                                       |
| `menu`        | 右クリックメニューに項目を追加する対象                                                                                                           |
| `hooks`       | フックを実行するタイミング → 対象                                                                                                                |
| `permissions` | WASM から使用するホスト権限の配列                                                                                                                |
| `required`    | 必須の外部コマンドと依存プラグイン                                                                                                               |
| `optional`    | 任意の外部コマンドと依存プラグイン                                                                                                               |
| `fetch`       | スクリプトの `api.fetch` と WASM の `host::fetch` で通信を許可するホスト名。サブドメインも含む。`com` のようなトップレベルドメイン単体は指定不可 |

## formats

| キー     | 内容                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------- |
| `ext`    | 拡張子（`.` なし）の配列。小文字に正規化される。`url` はアプリ本体がショートカットとして扱うため指定不可 |
| `label`  | 形式の表示名                                                                                             |
| `ratio`  | サムネイル生成前に使用する既定の縦横比（幅 / 高さ）                                                      |
| `fit`    | サムネイルの表示方法。`center`（既定、中央で切り抜き）・`top`（上端基準で切り抜き）・`contain`（全体表示） |
| `media`  | アプリ本体が標準プレーヤーで表示するメディア種別。`image`・`video`・`audio` のいずれか                   |
| `parts`  | 対応する機能（下表）                                                                                     |
| `script` | `parts` のうちスクリプトで処理するもの。指定しないものは WASM が処理する                                 |

| `parts`     | 内容                                                 | WASM | スクリプト |
| ----------- | ---------------------------------------------------- | ---- | ---------- |
| `thumbnail` | サムネイル生成                                       | ○    | ○          |
| `view`      | 詳細表示。WASM は PNG を返し、スクリプトは DOM に描画 | ○    | ○          |
| `details`   | ファイルの詳細欄に追加する行                         | ○    | ○          |
| `excerpt`   | AI 検索・自動分類のために抽出する区間データ          | ○    | ○          |
| `hover`     | サムネイルにカーソルを合わせたときのホバー表示       |      | ○          |
| `embed`     | ノートに埋め込んだときの表示                         |      | ○          |

- `media` を指定した形式は詳細表示とノートへの埋め込みをアプリ本体が標準コンポーネントで表示する。ホバー時は `video` を消音で再生し、`audio` を音声付きで再生する。`parts` に `view`・`hover`・`embed` が指定されている場合はプラグイン側の実装が優先される
- 同じ拡張子に外部プラグインとコア機能の両方が対応している場合は外部プラグインが優先される。複数の外部プラグインが同じ拡張子を指定した場合は競合となり、いずれも使用されない

## links

```json
"links": [{ "host": ["youtube.com", "youtu.be"], "parts": ["thumbnail", "view", "embed", "details"] }]
```

| キー    | 内容                                                                                                   |
| ------- | ------------------------------------------------------------------------------------------------------ |
| `host`  | ホスト名の配列。サブドメインも含む。複数一致する場合は最も長いホスト名の設定が使われる                 |
| `parts` | 対応する機能。指定できる値は `formats` の `parts` と同じで、すべてスクリプトが処理する                 |

- アプリ本体が扱うショートカット（`.url`）もリンク先 URL に一致するプラグインが処理する。`thumbnail`・`view`・`details`・`embed` に対応するプラグインがない場合はアプリ本体がページの OGP から生成する
- 同じホスト名を複数のプラグインが指定した場合は競合となり、いずれも使用されない

## screens

```json
"screens": {
  "graph": { "label": "ページの関係図", "icon": "diagram", "place": false }
}
```

| キー    | 内容                                                                                    |
| ------- | --------------------------------------------------------------------------------------- |
| `label` | ナビゲーションメニューやタブに表示する名前                                              |
| `icon`  | アプリ本体のアイコン名（`home`・`grid`・`note` など）。省略時はプラグインのアイコン     |
| `place` | ナビゲーションメニュー・コマンド・起動時の画面の選択肢に表示するか。既定は `true`       |

- 画面 ID には英数字・ハイフン・アンダースコアのみ使用できる
- 画面はタブとして開く。`place` が `false` の画面は右クリックメニューの実行結果（`screen`）から開く

## notes

```json
"notes": {
  "code": ["bars", "tally"],
  "script": ["tally"],
  "slash": [{ "label": "数える表", "icon": "plus", "keys": "tally count", "insert": "```tally\n$0\n```" }]
}
```

| キー     | 内容                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| `code`   | ```` ``` ```` の後ろに書く言語名の配列。小文字に正規化される                             |
| `script` | `code` のうちスクリプトで描画するもの。指定しないものは WASM が SVG または PNG を返す    |
| `slash`  | ノートの `/` メニューに追加する項目の配列（下表）                                        |

| `slash` のキー | 内容                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| `label`        | メニューに表示する名前                                                                                    |
| `icon`         | アプリ本体のアイコン名（`codeBlock`・`diagram`・`math` など）。省略時や未定義の名前はプラグインのアイコン |
| `keys`         | `/` メニューの絞り込みで名前のほかに一致させる検索語。空白区切りで指定する                                |
| `insert`       | 挿入するテキスト。カーソル行が空ならその行に、文字があれば次の段落として挿入し、`$0` の位置にカーソルを置く |

- 言語名は ```` ``` ```` の直後の最初の語と照合される
- WASM で描画したコードブロックはクリックするとコード編集に入る。スクリプトで描画したコードブロックは内部を操作できるため、右上の「コードを編集」ボタンから編集に入る
- 同じ言語名を外部プラグインとコア機能が指定した場合は外部プラグインが優先され、外部プラグインどうしが重複した場合はどちらも使用されない

## covers

```json
"covers": {
  "goal": { "label": "目標", "note": "件数の目標と進み具合", "on": ["tag", "project"] }
}
```

| キー       | 内容                                                                             |
| ---------- | -------------------------------------------------------------------------------- |
| `label`    | カードの見出しと「セクションを追加」メニューに表示する名前                       |
| `note`     | 「セクションを追加」メニューで名前の下に表示する補足説明                         |
| `on`       | 配置できる画面。`tag`（タグの概要）・`project`（プロジェクトの概要）。既定は両方 |
| `multiple` | 1 つの概要欄に複数配置できるか。既定は `false`                                   |

- カード ID には英数字・ハイフン・アンダースコアのみ使用できる
- カードはすべてスクリプトの `covers` で描画する
- 配置されたカードはライブラリの `.patchouli/` 下に `{ "type": "plugin", "plugin": "<id>", "card": "<カード ID>", "value": … }` として保存される。`value` はスクリプトが保存した JSON 値
- プラグインを無効化またはアンインストールするとカードは非表示になり、再度有効化すると保存された値とともに復元される

## menu と hooks

どちらも WASM で処理する（[wasm.md](wasm.md#menu-と-run-menu)）。

```json
"menu": { "formats": ["csv", "tsv"] },
"hooks": { "added": { "formats": ["md"] }, "changed": { "formats": ["md"] } }
```

`formats` には拡張子の配列、`all`（ノートを含む全項目）、`files`（ノートを除く全ファイル）のいずれかを指定する。ノートの拡張子は `md`。

- `menu` は選択中の項目がすべて `formats` に含まれる場合のみ右クリックメニューに項目を追加する。複数プラグインの項目はプラグインごとに区切って表示される
- `hooks` は `formats` に一致する項目ごとにバックグラウンドで順次呼び出される。同じ形式に対するフックが複数ある場合はプラグイン一覧の順に実行される

| `hooks`   | 実行タイミング                                                                                                                          |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `added`   | アプリに取り込んだとき。右クリックメニューで作成したノートや追加した素材も含む                                                          |
| `changed` | 内容が変更されたとき。ノートは編集後に画面を離れたとき、ファイルは外部での変更を検出したとき。素材はサイズと先頭・末尾 8 KB で判定する |
| `edited`  | 名前・タグ・所属が変更されたとき                                                                                                        |

## permissions

WASM から使用するホスト API の権限を指定する。ここに指定していないインターフェースを import する WASM は読み込まれない。各関数の詳細は [wasm.md](wasm.md#ホスト関数) を参照。

| 値          | 許可される操作                                   |
| ----------- | ------------------------------------------------ |
| `library`   | 素材やノートの名前・タグ・プロジェクトの読み取り |
| `embed`     | 文章のベクトル化と類似する素材・ノートの検索     |
| `clipboard` | クリップボードへのコピー                         |
| `notes`     | ノートの作成と本文の更新                         |
| `edit`      | 名前とタグの変更                                 |
| `assets`    | 素材の追加とファイル内容の置き換え               |
| `export`    | ライブラリ外へのファイルの書き出し               |

## required と optional

```json
"optional": {
  "commands": {
    "ffmpeg": {
      "version": { "args": ["-version"], "pattern": "ffmpeg version n?([0-9][^ ]*)" },
      "min": "6.0",
      "description": "AVIF のサムネイル生成と AI 機能での解析"
    }
  },
  "plugins": { "patchouli.image": { "min": "0.4.0" } }
}
```

| キー                          | 内容                                                                                                                               |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `commands.<名前>`             | 外部コマンド。PATH または設定で指定されたパスから検索する。WASM の `commands` で実行できるのはここに記載したコマンドのみ           |
| `commands.<名前>.min`         | 最小バージョン。指定する場合は `version` も必須                                                                                    |
| `commands.<名前>.version`     | バージョンの取得方法。`args` で実行し、標準出力・標準エラー出力から正規表現 `pattern` で抽出する（キャプチャグループがあれば第 1 グループ） |
| `commands.<名前>.description` | 用途の説明。プラグイン一覧の外部ツール欄に表示される                                                                               |
| `plugins.<id>.min`            | 依存プラグインの最小バージョン。スクリプトの `api.plugin(id)` から対象プラグインの WASM を呼び出せる                               |

`required` の条件を満たさないプラグインは無効（使用不可）になる。`optional` の条件を満たさない場合は一部の機能を利用できない旨が警告として表示される。
