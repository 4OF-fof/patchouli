# plugin.json

型は SDK の `manifest.ts`（`Manifest`）。アプリは読み込むときに中身を確かめ、合わないところをプラグインの一覧の「問題」に出す。

```json
{
  "id": "example_zip",
  "name": "example_zip",
  "version": "0.1.0",
  "description": "zip のサムネイルにアイコンを描き、詳細では中身をフォルダの木で見せる",
  "script": "ui.js",
  "formats": [
    { "ext": ["zip"], "label": "zip", "ratio": 1, "fit": "contain", "parts": ["thumbnail", "view"], "script": ["view"] }
  ]
}
```

## 上の階層

| キー          | 中身                                                                                                                                         |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`          | プラグインの ID。組み込みのプラグインと同じものは使えない                                                                                    |
| `name`        | 一覧に出す名前                                                                                                                               |
| `version`     | 版（semver）。ライブラリに記録した版と違うと、一覧に更新のボタンが出る                                                                       |
| `description` | 一覧に出す説明                                                                                                                               |
| `script`      | スクリプトのビルド後の `.js` のパス（plugin.json からの相対）。元は拡張子を `.ts` にしたもの                                                 |
| `formats`     | 同じ扱いの拡張子のまとまりの並び                                                                                                             |
| `links`       | 同じ扱いの URL のまとまりの並び                                                                                                              |
| `screens`     | 画面の ID → 足す画面                                                                                                                         |
| `menu`        | 右クリックメニューに項目を足す対象                                                                                                           |
| `hooks`       | フックを呼ぶとき → 対象                                                                                                                      |
| `permissions` | WASM に渡すホストの関数（下の表）                                                                                                            |
| `required`    | ないと動かないコマンドとプラグイン                                                                                                           |
| `optional`    | あれば使うコマンドとプラグイン                                                                                                               |
| `fetch`       | スクリプトの `api.fetch` と WASM の `host::fetch` で取りに行けるホスト名。サブドメインも含む。`com` のようなトップレベルドメインだけのものは書けない |

## formats

| キー     | 中身                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `ext`    | 拡張子（`.` なし）の並び。小文字にそろえて読む。`url` は本体がショートカットとして読むので使えない                                     |
| `label`  | 形式の呼び名                                                                                                                           |
| `ratio`  | サムネイルができるまで使う縦横比（幅 / 高さ）                                                                                          |
| `fit`    | サムネイルの枠への収め方。`center`（既定）・`top`（上の端を残して切り抜く）・`contain`（切り抜かずに収める）                           |
| `media`  | 本体がそのまま出す種類。`image`・`video`・`audio` のどれか                                                                             |
| `parts`  | 受け持つもの（下の表）                                                                                                                 |
| `script` | `parts` のうちスクリプトで受け持つもの。ほかは WASM が受け持つ                                                                         |

| `parts`     | 中身                                               | WASM | スクリプト |
| ----------- | -------------------------------------------------- | ---- | ---------- |
| `thumbnail` | サムネイル                                         | ○    | ○          |
| `view`      | 詳細の表示。WASM は PNG にし、スクリプトは描く     | ○    | ○          |
| `details`   | ファイルの詳細に足す行                             | ○    | ○          |
| `excerpt`   | 内容で探したり分けたりするときに読む区間           | ○    | ○          |
| `hover`     | カーソルを合わせたときにサムネイルの上に重ねる表示 |      | ○          |
| `embed`     | ノートに埋め込んだときの表示                       |      | ○          |

- `media` を書いた形式は、詳細の表示とノートへの埋め込みに本体がそのまま出す。カーソルを合わせたときは、`video` を音を消して再生し、`audio` を鳴らす。`parts` の `view`・`hover`・`embed` があれば、そちらを使う
- 同じ拡張子を外部のプラグインと組み込みのプラグインが書くと、外部のものを使う。外部のプラグインどうしが書くと、その外部のものはどれも使わず、組み込みがあればそれを使う

## links

```json
"links": [{ "host": ["youtube.com", "youtu.be"], "parts": ["thumbnail", "view", "embed", "details"] }]
```

| キー    | 中身                                                                                                      |
| ------- | --------------------------------------------------------------------------------------------------------- |
| `host`  | ホスト名の並び。サブドメインも含む。当てはまるものが複数あれば、いちばん長いホスト名のものを使う          |
| `parts` | 受け持つもの。書けるものは `formats` の `parts` と同じで、すべてスクリプトが受け持つ                      |

- 本体が読むショートカット（`.url`）も、指す URL に当てはまるものが描く。`thumbnail`・`view`・`details`・`embed` は、受け持つものがなければ本体がページの OGP から作る
- 同じホスト名を複数のプラグインが書くと、どれも使わない

## screens

```json
"screens": {
  "graph": { "label": "ページの関係図", "icon": "diagram", "place": false }
}
```

| キー    | 中身                                                                                     |
| ------- | ---------------------------------------------------------------------------------------- |
| `label` | 場所のメニューやタブに出す名前                                                           |
| `icon`  | 本体のアイコンの名前（`home`・`grid`・`note` など）。書かないときはプラグインのアイコン  |
| `place` | 場所のメニュー・コマンド・起動時に開く画面に並べるか。既定は `true`                      |

- 画面の ID には英数字・ハイフン・下線を使う
- 画面はタブで開く。`place` が `false` の画面は、右クリックメニューの結果の `screen` で開く

## menu と hooks

どちらも WASM が受け持つ（[wasm.md](wasm.md#menu-と-run-menu)）。

```json
"menu": { "formats": ["csv", "tsv"] },
"hooks": { "added": { "formats": ["md"] }, "changed": { "formats": ["md"] } }
```

`formats` は、拡張子の並び、`all`（ノートも含めたすべて）、`files`（ノートを除いたすべて）のどれか。ノートは `md`。

- `menu` は、選んだものがすべて `formats` に入るときだけ項目を足す。対象が重なるプラグインの項目は、プラグインごとに区切って並ぶ
- `hooks` は、`formats` に入るもの 1 つごとに裏で呼ぶ。同じ形式のフックはプラグインの一覧の順に呼ぶ

| `hooks`   | 呼ぶとき                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------- |
| `added`   | アプリで取り込んだとき。右クリックメニューで作ったノートと登録した素材も含む                        |
| `changed` | 中身が変わったとき。ノートは書き換えて離れたとき、ファイルはアプリの外で変わったのを見つけたとき    |
| `edited`  | 名前・タグ・置き場を変えたとき                                                                      |

## permissions

WASM で使う関数のまとまりを書く。書いていないものを import する WASM は読み込まない。関数は [wasm.md](wasm.md#ホストの関数) に書いてある。

| 値          | できること                                   |
| ----------- | -------------------------------------------- |
| `library`   | 素材やノートの名前・タグ・プロジェクトを読む |
| `embed`     | 文章をベクトルにし、近い素材とノートを探す   |
| `clipboard` | クリップボードに写す                         |
| `notes`     | ノートを作り、本文を書き換える               |
| `edit`      | 名前とタグを変える                           |
| `assets`    | 素材を登録し、中身を置き換える               |
| `export`    | ライブラリの外へ書き出す                     |

## required と optional

```json
"optional": {
  "commands": {
    "ffmpeg": {
      "version": { "args": ["-version"], "pattern": "ffmpeg version n?([0-9][^ ]*)" },
      "min": "6.0",
      "description": "AVIF のサムネイルを作れます"
    }
  },
  "plugins": { "patchouli.image": { "min": "0.4.0" } }
}
```

| キー                          | 中身                                                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `commands.<名前>`             | 手元のコマンド。PATH から探す。WASM の `commands` で動かせるのは、ここに書いたものだけ。コマンドはアプリと同じ権限で動く |
| `commands.<名前>.min`         | 版の下限。書くときは `version` も書く                                                                                    |
| `commands.<名前>.version`     | 版の取り方。`args` で動かし、出力から `pattern` で拾う（グループがあれば最初のグループ）                                 |
| `commands.<名前>.description` | 何に使うか。一覧に出す                                                                                                   |
| `plugins.<id>.min`            | ほかのプラグインの版の下限。スクリプトの `api.plugin(id)` で、その WASM を呼べる                                         |

`required` を満たさないプラグインは使えない。`optional` を満たさないときは、一部の機能を使えないと一覧に出す。
